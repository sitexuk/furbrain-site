# Furbrain website

The public website for Furbrain, the iPhone app that tells you what your pet is thinking.
Plain HTML and CSS, published with GitHub Pages from the `main` branch.

| Page | Used for |
| --- | --- |
| `index.html` | Home page |
| `about.html` | About |
| `support.html` | App Store **Support URL** |
| `privacy.html` | App Store **Privacy Policy URL** |

Shared styles live in `styles.css`. Contact: furbrain.help@icloud.com.
